日期：2026-11-05（Asia/Shanghai）。范围仅 D1；需求 1.3、实施契约 1.2 与已批准的数据库命名补充。**D1 已完成：local=passed，external=not_applicable，overall=passed。本轮停止，不进入 D2，不提交/推送 Git。** 最终状态见[阶段交接汇总](2026-11-05_D1_credentials/final-summary.json)，阶段范围见[D1 任务卡](../tasks/D1_PostgreSQL与只读业务.md#必需测试)。

## 非技术读者快速了解 D1

本阶段让程序能够安全连接真实 PostgreSQL，读取比赛数据、计算金额、检查用途规则，并验证“哪些内容允许读写、哪些操作必须拒绝”。本轮用户自行调整维护角色密码后，之前的凭证阻塞解除。五类连接均登录成功；先准备测试库、跑完整验收，再准备开发库，没有用其他数据库替代。

现在测试库和开发库都已有 harness schema、16 张表（15 张业务/技术表加 Alembic 版本表）、规范化初始资料和最小运行权限。216 项测试全部通过，其中 169 项单元测试、47 项真实 PostgreSQL 集成/API 测试；另在开发库上用真实本机 HTTP 验证了 6 项健康、身份、金额和权限行为。[测试汇总](2026-11-05_D1_credentials/summary.json)、[JUnit](2026-11-05_D1_credentials/attempt1/pytest.xml)和[HTTP 记录](2026-11-05_D1_credentials/development-http.json)分别证明这些结论。

项目负责人无需再次初始化当前数据库。日常使用按[根 README](../../../README.md#8-日常启动)启动；业务接口需要先在本机配置两项独立演示令牌。本轮 HTTP 使用子进程临时令牌，未写入 .env、未持久保存令牌。聊天、模型工具循环和后续写入/记忆流程属于后续阶段，D1 通过不代表这些功能已经完成。D2 须另行明确启动，本轮不推进。

## 本轮修复与失败证据

真实验收暴露了两个先前未执行到的实现缺陷，均在测试库修复后重新通过：

1. 首迁移中的 JSONB 默认表达式被错误当作字符串再次加引号，PostgreSQL 以 22P02 拒绝建表。此次迁移事务回滚。修正[模型 JSON 默认表达式](../../../backend/app/infrastructure/database/models.py)与尚未成功应用的[首迁移 SQL](../../../backend/migrations/versions/0001_initial.sql)，没有改变既定字段/约束含义。保留[首次退出 4](2026-11-05_D1_credentials/migrate-test.json)及[脱敏诊断](2026-11-05_D1_credentials/migration-diagnostic.log)，[修复后迁移退出 0](2026-11-05_D1_credentials/migrate-test-retry.json)。未对已有版本成功的库偷偷改迁移历史；开发库随后才首次执行该迁移。
2. 授权 SQL 中 PostgreSQL format 的 `%I` 被驱动当成参数占位符。固定 SQL 改由[同一受保护事务内无参数 cursor 执行](../../../backend/app/infrastructure/database/maintenance.py)，来源与权限校验不变。保留[首次退出 4](2026-11-05_D1_credentials/grant-test.json)、[诊断](2026-11-05_D1_credentials/grant-diagnostic.log)及[复验退出 0](2026-11-05_D1_credentials/grant-test-retry.json)。

2026-11-04 的 106/47、149/169 单测、共用口令拒绝及停止记录保持历史原样，见[当期报告](2026-11-04_D1.md)和[当期恢复报告](2026-11-04_D1_真实验收恢复.md)。本轮业务需求与三份机器接口契约 hash 未变，证据见[受保护输入检查](2026-11-05_D1_credentials/summary.json)的 protected_inputs/protected_inputs_against_D0，不以口头“未变更”代替差异核验。
