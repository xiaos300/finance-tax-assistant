运行最小权限：companies、user_company_permissions、bank_transactions、rules/rule_companies、seed_meta、alembic_version 只读；users 只 SELECT 和 UPDATE(memory_revision)；invoices 只 SELECT 和 UPDATE(purpose,note,row_version,updated_at)，禁止 INSERT/DELETE 或金额等列更新；其余会话/轮/记忆/账本/证据及 event 序列按需要显式授权，不使用全表全量 DML。grant-runtime 先撤销**项目 schema 内**过宽表级授权，再授列级白名单，不动其他 schema。依据[基础表权限](../../architecture/05_数据库与数据架构设计.md#31-companiesusersuser_company_permissions)、[角色契约](../../architecture/12_开发实施契约补充.md#63-运行角色与bootstrap)及[官方 GRANT](https://www.postgresql.org/docs/18/sql-grant.html)。

### 2. 本机受控认证和只读核对

确认复用实例后，操作者在本机提供获准身份；口令通过 psql -W 提示输入，不写聊天/命令行。以下模板本轮未运行，-X 忽略个人 psqlrc，ON_ERROR_STOP 遇错停止，选项依据[官方 psql](https://www.postgresql.org/docs/18/app-psql.html)。

```powershell
$pgBin = 'E:\developmentEnvs\postgreSQL\bin'
$bootstrapUser = Read-Host '本机已获授权的 PostgreSQL 维护用户名'
$readOnlyAudit = @(
  'BEGIN READ ONLY;'
  'SHOW server_version;'
  'SHOW server_encoding;'
  'SELECT current_database(), current_user;'
  "SELECT datname, pg_encoding_to_char(encoding) AS encoding, pg_get_userbyid(datdba) AS owner FROM pg_database WHERE datname IN ('harness','harness_test_d1');"
  "SELECT rolname, rolsuper, rolcreatedb, rolcreaterole, rolcanlogin FROM pg_roles WHERE rolname IN ('harness_migrator','harness_app');"
  'COMMIT;'
) -join [Environment]::NewLine
& "$pgBin\psql.exe" -X -W -h 127.0.0.1 -p 5432 -U $bootstrapUser -d postgres -v ON_ERROR_STOP=1 -c $readOnlyAudit
```

postgres 是维护连接候选库，尚未认证确认可用；不可用时由操作者给出正确目标，不猜密码、不改 trust/pg_hba。若项目库已存在，得到查看许可后再只读检查该库 schema、alembic_version/seed_meta、表和权限；不把已有数据自动视作本项目。需确认实际 SQL 服务器版本、UTF-8、角色属性/继承与权限，不能只看 readiness。
